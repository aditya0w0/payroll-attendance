- Date: 2026-11-20
- Context: Pre-client shipment hygiene audit, test debris purging, and test coverage assessment
- Scope: Database state, login form inputs, configuration templates, build verification, and test coverage

## 1. Development Residue Audit Findings

1. Database Pollution:
   - Issue: Successive automated test runs had left 47 synthetic test users (such as `test_arch_*`, `rogue_*`, `test_conc_a`, `test_conc_b`, `test_quarantine_emp`, `test_proxy_emp`), 128 device unlock requests, 1191 expired QR challenges, and over 1300 synthetic test audit logs inside the database.
   - Resolution: Developed and executed `scripts/reset-clean-seed.ts` (added to `package.json` as `npm run db:clean`), which safely suspended table triggers, cascaded truncation across all test data, restored database immutability triggers, and seeded canonical baseline accounts.
   - Verification: Database confirmed containing exactly 4 accounts (1 Owner, 3 Employees), 2 registered devices, 1 reference attendance record, 0 orphaned challenges, and 3 genesis cryptographic audit logs.

2. Hardcoded Credentials in Login Component:
   - Issue: `src/app/login/page.tsx` prefilled email and password state with `"siti@company.com"` and `"employee123"` (and `"owner@company.com"` / `"admin123"` on mode change).
   - Resolution: Reset initial state to empty strings (`""`) and updated input placeholders to generic domain examples (`nama@perusahaan.com` / `owner@perusahaan.com`).

3. Environment Configuration Hygiene:
   - Issue: `.env.example` contained concrete test secrets in `SESSION_SECRET` and `CRON_SECRET`.
   - Resolution: Replaced with descriptive placeholder instructions (`[generate-random-32-byte-secret-key]` and `[random-secret-for-cron-worker]`). Corrected variable naming in `README.md`.

4. Local Artifacts & Backups:
   - Cleaned up local `.DS_Store` and `.bak` files across workspaces.
