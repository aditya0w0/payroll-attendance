## Detailed Findings

### Finding 1: Copywriting Em Dash (`—`) in UI Text
- **Rule**: R-02 (Copywriting)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/owner/shifts/page.tsx` (lines 357-358), `src/app/employee/scan/page.tsx` (lines 172, 175, 177)
- **One-line reason**: The em dash character is strictly forbidden in UI text and must be replaced with colons, parentheses, or commas.
- **Proposed Remedy**: Replace `Mode A — Per Minute` with `Mode A: Per Minute`, and replace `${rawReason} — Sinyal GPS...` with `${rawReason}: Sinyal GPS...`.

### Finding 2: Sub-44px Mobile Tap Targets on Critical Interactive Controls
- **Rule**: R-03 (Mobile Responsiveness) / `antislop-layoutmobile`
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/owner/layout.tsx` (nav bar), `src/components/owner/DashboardAnalytics.tsx` (range selector), `src/app/owner/attendance/page.tsx` (tabs)
- **One-line reason**: Interactive buttons with heights between 26px and 32px fail the minimum 44x44px touch target required for thumb navigation on mobile screens.
- **Proposed Remedy**: Enforce `min-h-[44px]` touch targets or equivalent hit-area padding with generous spacing between adjacent touch targets.

### Finding 3: Color Contrast Degradation on Translucent Glass Surfaces
- **Rule**: R-25 (Color Contrast)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/globals.css`, `src/app/layout.tsx`
- **One-line reason**: Low-opacity glass backgrounds placed over colored background orbs drop text contrast below the mandatory WCAG AA 4.5:1 ratio across different scroll positions.
- **Proposed Remedy**: Solidify card backgrounds to high-contrast opaque surface tokens (`#ffffff` with crisp borders in light mode, `#111827` / `#0f172a` in dark mode) guaranteeing 7:1+ contrast.

### Finding 4: Modal Dialogs Lack Keyboard Escape Handler
- **Rule**: R-32 (Keyboard Accessibility)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/components/owner/EmployeeAttendanceRoster.tsx` (line 343), `src/app/owner/employees/page.tsx` (line 310)
- **One-line reason**: Accessible modals must be closable using the keyboard `Escape` key and return focus to the trigger element.
- **Proposed Remedy**: Add `useEffect` event listener for `Escape` key on open modals and include an explicit, labeled close button.

### Finding 5: Missing Interaction Affordances and Reduced Motion Guards
- **Rule**: R-39 (Accessible Semantics & Interaction Affordances)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/globals.css`
- **One-line reason**: Interactive elements must guarantee `cursor: pointer`, and continuous animations must respect user OS reduced motion preferences.
- **Proposed Remedy**: Declare global `cursor: pointer` on interactive selectors and add `@media (prefers-reduced-motion: reduce)` to disable spin and pulse animations.

### Finding 6: Generic Blue-Purple Gradient and Ambient Nebula Glow
- **Rule**: R-01 (Color & Gradients) / `antislop-ui`
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/layout.tsx` (lines 45-60)
- **One-line reason**: Ambient purple-blue blurred radial mesh orbs are the primary visual tell of generic AI-generated templates.
- **Proposed Remedy**: Remove the 5 floating blur orbs in `RootLayout`. Replace with a solid, high-contrast canvas background (`#f8fafc` in light mode, `#090d16` in dark mode).

### Finding 7: Excessive Glassmorphism on Every Surface
- **Rule**: R-10 (Glassmorphism) / `antislop-ui`
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/globals.css`, `src/app/owner/*`, `src/app/employee/*`
- **One-line reason**: Applying `backdrop-filter: blur(28px)` to headers, metric cards, charts, tables, badges, and modals simultaneously violates the 1-2 element dose cap and flattens hierarchy.
- **Proposed Remedy**: Restrict glass treatment strictly as an accent to the floating bottom navigation dock (1 element). Convert all dashboard cards, metric tiles, tables, and dialogs into clean, solid, opaque surface cards with crisp hairline borders.

### Finding 8: Redundant Eyebrow Capsule Badges
- **Rule**: R-09 (Badges) / `antislop-ui`
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/owner/qr/page.tsx` (line 55), `src/app/employee/scan/page.tsx`
- **One-line reason**: Eyebrow capsule pills parked directly above H1 titles serve as decorative AI filler repeating what the title already states.
- **Proposed Remedy**: Remove decorative eyebrow pills; reserve badges strictly for functional status indicators (e.g., Active, Completed, Pending).

### Finding 9: Overly Soft Dual Shadows and Specular Meniscus Insets
- **Rule**: R-12 (Shadow) / `antislop-ui`
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/globals.css`
- **One-line reason**: Applying deep 36px/50px diffused shadows and dual specular white insets across all cards eliminates true visual elevation and creates visual softness.
- **Proposed Remedy**: Replace with subtle, single-tier border-driven elevation: crisp 1px neutral borders (`border-neutral-200` / `border-neutral-800`) and concise 1px-2px shadows.

### Finding 10: Decorative Arrow Glyphs Attached to All CTAs
- **Rule**: R-08 (Button Arrows)
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/owner/page.tsx`, `src/components/owner/DashboardAnalytics.tsx`
- **One-line reason**: Trailing arrow glyphs (`ArrowRight`) used ubiquitously on secondary links and view buttons act as unneeded visual noise.
- **Proposed Remedy**: Remove decorative arrows from standard navigation and table links; retain clear contextual action text.

### Finding 11: Uniform Pill Radius Erasing Component Visual Language
- **Rule**: R-11 (Border Radius) / `antislop-ui`
- **Tier**: Quality Lock
- **Priority**: LOW
- **Location**: `src/app/globals.css`, `src/components/owner/*`
- **One-line reason**: Rendering cards, badges, inputs, and tab containers in uniform pill shapes (`rounded-3xl` / `rounded-full`) degrades the distinction between interactive controls and container surfaces.
- **Proposed Remedy**: Standardize to an intentional radius hierarchy: `rounded-lg` (8px) for buttons and inputs, `rounded-xl` (12px) for content cards, and `rounded-md` (6px) for status tags.

### Finding 12: Fragmented Multi-Hue Accent Palette
- **Rule**: R-29 (Color Palette)
- **Tier**: Quality Lock
- **Priority**: LOW
- **Location**: `src/app/globals.css`
- **One-line reason**: Using multiple competing pastel tints and glowing fills on status pills diffuses brand cohesion.
- **Proposed Remedy**: Unify the palette to 1 neutral scale, 1 primary action color (deep sapphire blue), and purposeful semantic accents (emerald for present, amber for late, ruby for alerts).
