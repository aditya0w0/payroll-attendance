# Anti-Slop Audit Report #009

Date: 2026-11-20
Target: Halaman Pemindai Presensi Karyawan (/employee/scan)
Audit Scope: Penanganan error perizinan GPS dan kamera, pencegahan kebocoran error code teknis mentah ([CODE 1], Invalid constraint), integrasi kartu diagnostik perizinan, dan pembersihan elemen pengujian demo.
Standard: Anti Slop Rules for AI Coding Agents (R-01 to R-40), antislop-ui, antislop-copywriting, antislop-human
Mode: Mode 2 (After Audit)

---

## Executive Summary

Menindaklanjuti keluhan pengguna ("masih slop") pada tangkapan layar pemindai karyawan (`/employee/scan`), dilakukan audit mendalam pada penanganan error dan antarmuka izin perangkat.

Masalah utama yang ditemukan:
1. **Kebocoran Error Code Browser Mentah pada GPS**: Antarmuka membocorkan kode error teknis browser internal `[CODE 1] User denied Geolocation` kepada pengguna awam, bukan pesan panduan manusiawi yang ramah dan jelas.
2. **Kebocoran Pesan OverconstrainedError Kamera Mentah**: Ketika kamera gagal mengikat resolusi atau facingMode, sistem menampilkan teks teknis mentah `Invalid constraint` tanpa penanganan fallback otomatis ke resolusi dasar atau penjelasan bahwa kamera sedang dipakai aplikasi lain.
3. **Penyusunan Alert Bertumpuk (Alert Chaos)**: Kotak peringatan izin GPS kuning dan kotak error kamera merah muda muncul bertumpuk secara terpisah, mendominasi layar dengan kesan rusak dan membingungkan pengguna.
4. **Teks Campuran dan Simbol Panah**: Teks panduan izin menggunakan simbol panah (`->`) yang melanggar aturan copywriting, serta mencampur istilah teknis bahasa Inggris (`Precise Location`, `User denied`) di tengah kalimat bahasa Indonesia.
5. **Elemen Pengujian / Debug Internal Mengotori Layar**: Blok accordion "Opsi Pengujian / Manual Token (Khusus Demo)" dengan tombol "Ambil QR Aktif Terminal Otomatis (1-Tap Test)" dan ikon petir tampil mencolok di layar utama presensi karyawan.

Sesuai panduan antislop Mode 2, tidak ada berkas kode yang dimodifikasi sebelum nomor temuan disetujui.

## Detailed Findings

### Finding 1: Kebocoran Error Code Mentah Geolocation ([CODE 1])
- **Rule**: R-16 (Copywriting & Buzzwords), R-27 (UI States & Error Handling)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/employee/scan/page.tsx` (lines 220-233)
- **One-line reason**: Antarmuka membocorkan variabel kode error teknis browser `[CODE 1] User denied Geolocation` ke hadapan pengguna.
- **Proposed Remedy**: Bersihkan pesan error dari variabel teknis mentah. Gunakan bahasa Indonesia manusiawi: "Izin akses lokasi belum diaktifkan pada browser. Silakan izinkan akses lokasi melalui setelan situs browser Anda."

### Finding 2: Kebocoran Error Overconstrained Kamera ("Invalid constraint")
- **Rule**: R-35 (Resilience & Error Fallback), R-16 (Copywriting)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/employee/scan/page.tsx` (lines 318-382)
- **One-line reason**: Kesalahan getUserMedia memuntahkan pesan teknis internal `Invalid constraint` tanpa mekanisme fallback resolusi kamera.
- **Proposed Remedy**: Tambahkan cascade fallback bertingkat saat inisialisasi kamera (jika constraint ideal 1280x720 gagal, coba `{ video: true }`, jika tetap gagal berikan pesan manusiawi: "Kamera tidak dapat diakses atau sedang digunakan oleh aplikasi lain").

### Finding 3: Alert Stack Chaos (Tumpukan Kotak Peringatan Warna-Warni)
- **Rule**: R-14 (Component Craftsmanship), R-20 (Visual Identity)
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/employee/scan/page.tsx` (lines 880-960)
- **One-line reason**: Layar dipenuhi tumpukan kotak peringatan terpisah (kuning untuk GPS, merah muda untuk kamera) yang membuat antarmuka terasa rusak.
- **Proposed Remedy**: Satukan pemeriksaan kesiapan perangkat (Kamera dan GPS) ke dalam satu kartu status perizinan yang ringkas, elegan, dan tenang bergaya Apple HIG.

### Finding 4: Penggunaan Karakter Panah (->) dan Bahasa Campuran
- **Rule**: R-02 (Copywriting: Natural & Human Text)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/employee/scan/page.tsx` (lines 224-225)
- **One-line reason**: Teks panduan menggunakan simbol panah `->` dan istilah bahasa Inggris yang tidak konsisten.
- **Proposed Remedy**: Ubah kalimat menjadi panduan langkah yang runtut tanpa simbol panah, menggunakan bahasa Indonesia baku dan jelas.

### Finding 5: Panel Pengujian Demo Mengotori Alur Presensi Karyawan
- **Rule**: R-31 (Every Decision Must Have a Reason), R-05 (Page Structure)
- **Tier**: Quality Lock
- **Priority**: LOW
- **Location**: `src/app/employee/scan/page.tsx` (lines 1000-1040)
- **One-line reason**: Tombol pengujian demo seperti "Ambil QR Aktif Terminal Otomatis (1-Tap Test)" dengan ikon petir tampil mencolok pada alur kerja presensi resmi.
- **Proposed Remedy**: Sembunyikan panel opsi pengujian jika bukan lingkungan lokal/dev murni, atau kemas menjadi opsi diagnostik bantuan yang tidak mengganggu alur utama.
