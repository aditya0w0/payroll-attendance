Date: 2026-11-20
Target: Keamanan Perangkat (/owner/devices) & Cetak Slip Gaji (/owner/payroll, /employee)
Audit Scope: Comprehensive review of device security management (/owner/devices) and payroll slip print architectures (/owner/payroll, /employee).
Standard: Anti Slop Rules for AI Coding Agents (R-01 to R-40), antislop-ui, antislop-copywriting, antislop-human
Mode: Mode 2 (After Audit)

## Executive Summary

Following user feedback ("Keamanan perangkat masih slop, pengajian cetak slip itu masih slop, sejak kapan slip gaji kek gitu tampilannya"), an in-depth audit of `/owner/devices` and `/owner/payroll` was conducted.

Key craftsmanship failures identified:
1. **Robotic English Microcopy & Leaked Technical Enums in Device Security**: `/owner/devices` contains widespread English microcopy (`Pending Unlock & Replacement Requests`, `Attempted Terminal`, `Direct Approve`, `Reset Device Binding`), awkward robotic placeholder sentences, and raw database enums (`Assurance Tier: HIGH_HARDWARE_BOUND`).
2. **Artificial SMS-OTP Digit Box Simulation**: The 6-digit unlock code is rendered inside 6 individual input-style boxes, simulating an OTP entry form rather than presenting an authoritative administrative authorization code.
3. **Inconsistent Class Tokens & Mismatched Button Styles**: The device security page mixes legacy `apple-card`, `liquid-glass`, and `apple-btn-secondary` classes with Apple HIG design system tokens.
4. **SaaS Dashboard Widget Masquerading as a Print Document**: In `/owner/payroll`, the print modal displays 3 giant colored dashboard KPI metric cards (`Rp150.000`, `-Rp6.000`, `Rp144.000`) in the middle of what is supposed to be a printed financial document. Real business documents do not look like SaaS web dashboards.
5. **Conflation of "Slip Gaji" and "Rekapitulasi Penggajian"**: The button is titled `Cetak Slip / PDF`, but opening it reveals a multi-employee company ledger containing all employees. A "Slip Gaji" in Indonesian and international payroll standards is an individual employee document.
6. **Total Absence of an Authentic Slip Gaji Karyawan**: The platform currently possesses no way to view or print an individual employee's salary slip. An authentic Indonesian payslip requires: Kop Dokumen / Nama Usaha, Judul `SLIP GAJI KARYAWAN`, NIK & Shift Karyawan, Rincian Penerimaan (Gaji Pokok x Hari Kerja), Rincian Potongan (Denda Keterlambatan), Total Gaji Bersih (Take Home Pay), Kalimat Terbilang Rupiah, serta Kolom Tanda Tangan Pengesahan (Penerima & Keuangan).
7. **English Copywriting Leakage in Employee Payslip Cards**: In `/employee`, the daily payslip receipt card is written entirely in English (`Daily Salary Receipt`, `Base Daily Salary`, `Scheduled Check-In`, `Net Daily Earnings`, `Authoritative Server Snapshot`).

Below is the prioritized list of 7 actionable findings. Per antislop guidelines (Mode 2), no code files will be modified until you approve the specific numbers to fix.

## Detailed Findings

### Finding 1: Robotic English Microcopy & Plumbing in Device Security
- **Rule**: R-16 (Copywriting - Buzzwords & Tech Jargon), antislop-copywriting
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/owner/devices/page.tsx` (lines 280-345)
- **One-line reason**: The pending unlock section is written in robotic English (`Pending Unlock & Replacement Requests`, `Attempted Terminal`, `Direct Approve`), creating cognitive friction for Indonesian business owners.
- **Proposed Remedy**: Localize completely to professional Indonesian (`Permintaan Buka Kunci & Pergantian Perangkat`, `Perangkat Asal`, `Perangkat Baru`, `Setujui Pembukaan`), and replace robotic empty state text with clear factual copy.

### Finding 2: Artificial SMS-OTP Digit Box Simulation in Unlock Code
- **Rule**: R-14 (Component Craftsmanship), antislop-ui
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/owner/devices/page.tsx` (lines 350-375)
- **One-line reason**: Splitting the 6-digit code into 6 separate bordered square boxes mimics a user OTP input form rather than an administrative authorization code.
- **Proposed Remedy**: Render as a single, elegant monospace authorization code badge (`tracking-widest font-mono text-base font-semibold text-blue-600`) with a clean copy-to-clipboard action.

### Finding 3: English Section Titles, Raw Enums, and Inconsistent Tokens in Terminals Table
- **Rule**: R-29 (Color Tokens), R-16 (Technical Enums), R-20 (Visual Polish)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/owner/devices/page.tsx` (lines 405-560)
- **One-line reason**: The terminals table uses English titles (`Registered Employee Terminals & Passkeys`), leaks raw database enums (`Assurance Tier: HIGH_HARDWARE_BOUND`), and uses mismatched legacy `apple-card` / `apple-btn` tokens.
- **Proposed Remedy**: Standardize on Apple HIG design tokens (`hig-card`, `hig-button-secondary`), translate headers and tier labels to Indonesian (`Hardware Terikat (Biometrik Aman)`, `Passkey Platform`), and localize the reset confirm dialogue.

### Finding 4: Tacky SaaS Dashboard Metric Cards inside Print Document
- **Rule**: R-14 (Component Craftsmanship), R-01 (Color Semantic Tint)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/owner/payroll/page.tsx` (lines 345-368)
- **One-line reason**: The print modal features 3 large colored SaaS dashboard KPI cards (`Rp150.000`, `-Rp6.000`, `Rp144.000`) looking like a web analytics widget instead of a formal accounting document.
- **Proposed Remedy**: Remove the SaaS card widgets and format the financial totals as a clean, formal accounting ledger summary (Total Gaji Kotor, Total Potongan Denda, Total Gaji Bersih) with standard tabular alignment.

### Finding 5: Conflation of "Slip Gaji" and "Rekapitulasi Penggajian"
- **Rule**: R-24 (Honest Actions), antislop-copywriting
- **Tier**: Purpose-Gate
- **Priority**: HIGH
- **Location**: `src/app/owner/payroll/page.tsx` (lines 185-195)
- **One-line reason**: Labeling a whole-company ledger modal as `Cetak Slip / PDF` creates confusion because a "Slip Gaji" is an individual employee document.
- **Proposed Remedy**: Rename the global button to `Cetak Rekap Gaji (PDF)`, and add a dedicated `Cetak Slip` button on each employee row in the payroll table.

### Finding 6: Total Absence of an Authentic Indonesian Slip Gaji Karyawan
- **Rule**: R-20 (Visual Identity), R-31 (Every Decision Must Have a Reason)
- **Tier**: Hard Gate
- **Priority**: HIGH
- **Location**: `src/app/owner/payroll/page.tsx` (lines 292-428)
- **One-line reason**: The platform has no individual Slip Gaji format matching standard Indonesian payroll practices.
- **Proposed Remedy**: Implement an authentic, print-ready `Slip Gaji Karyawan` modal for individual employees featuring:
  1. Kop Usaha & Identitas Dokumen (`SLIP GAJI KARYAWAN`)
  2. Data Identitas: Nama Karyawan, ID/NIK, Jabatan/Shift, Periode Penggajian, Status Kerja
  3. Tabel Komponen Gaji: Rincian Penerimaan (Gaji Pokok x Hari Hadir) & Rincian Potongan (Denda Keterlambatan)
  4. Total Gaji Bersih (Take Home Pay)
  5. Konversi Terbilang Rupiah otomatis (e.g. "Seratus Empat Puluh Empat Ribu Rupiah")
  6. Catatan Kehadiran (Jumlah Hari Masuk & Total Menit Terlambat)
  7. Kolom Pengesahan Tanda Tangan: Diterima oleh (Karyawan) & Dibuat oleh (Manajemen/Keuangan)

### Finding 7: English Technical Terms in Employee Payslip Cards
- **Rule**: R-16 (Copywriting - Language Consistency)
- **Tier**: Purpose-Gate
- **Priority**: MEDIUM
- **Location**: `src/app/employee/page.tsx` (lines 440-515)
- **One-line reason**: The employee portal displays daily earnings receipts with English labels (`Daily Salary Receipt`, `Base Daily Salary`, `Net Daily Earnings`, `Authoritative Server Snapshot`).
- **Proposed Remedy**: Localize to natural Indonesian (`Slip Gaji Harian`, `Gaji Pokok Harian`, `Jadwal Shift`, `Jam Masuk`, `Pendapatan Bersih`, `Snapshot Terverifikasi Sistem`).
